# 🎬 Samra YouTube Pro Downloader & Uploader Bot

A high-performance Telegram bot to download YouTube Videos in all resolutions (144p to 4K) and MP3 audios (128kbps / 320kbps) with dynamic visual progress bar and high-speed streaming engine.

## 🚀 Features
- 💎 **All Resolutions Supported:** 144p, 240p, 360p, 480p, 720p HD, 1080p FHD, 1440p 2K, 2160p 4K.
- 🎵 **Ultra High-Quality MP3:** 320 kbps & 128 kbps audio options.
- 📊 **Dynamic Visual Progress Bar:** Live percentage, speed (MB/s), ETA, and uploaded size.
- 🖼 **Rich Media Previews:** Video thumbnails, title, duration, and direct streaming links.
- 🛡 **Resilient Stream Pipeline:** Concurrent chunk streaming with automatic temporary file cleanup.

## ⚙️ Configuration
Create a `.env` file or export environment variables:
```env
API_ID=12345678
API_HASH=your_api_hash_here
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
ADMIN_ID=123456789
API_BASE=https://samra-youtube-api.krishnalucky193.workers.dev
BOT_SESSION=
```

## 🛠️ Installation & Running
```bash
pip install -r requirements.txt
python bot.py
```
